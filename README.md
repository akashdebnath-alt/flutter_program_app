# Flutter Program App

A mobile app that helps learners discover, enroll in, and track learning programs, while giving admins a simple way to manage those programs.

## Project Vision
Make learning programs easy to find and easy to manage. Learners get one place to browse programs and follow their progress. Admins get one place to create and update programs.

## Objectives
- Let learners register, log in, and browse available programs
- Show clear details for each program (description, duration, mentor)
- Allow learners to enroll and view their enrolled programs
- Allow admins to add, edit, and remove programs
- Build a clean, simple UI using Flutter and Dart

## Target Users
- **Learners:** students who want to explore and join programs
- **Admins:** staff who create and manage programs

## Navigation Flow
Login -> Home -> Program Listing -> Program Details -> Enroll
Home -> Profile -> Feedback Form
Admin: Login -> Admin Dashboard -> Add / Edit Program

## Tech Stack
- Flutter (Dart)
- VS Code
- Git and GitHub

## Project Structure
- `lib/` - Dart code (screens and logic)
- `pubspec.yaml` - dependencies and assets
- `android/`, `ios/` - platform-specific code
